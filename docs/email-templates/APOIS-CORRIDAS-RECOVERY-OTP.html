Código para redefinir sua senha

Recebemos uma solicitação de recuperação de senha para sua conta APOIS. Abra o aplicativo e digite o código temporário:

SEU CÓDIGO DE VERIFICAÇÃO {{ .Token }}

No aplicativo APOIS, acesse Esqueci minha senha, informe seu e-mail e digite o código. Não compartilhe este número com ninguém.

Este código é de uso único e expira conforme o prazo configurado na autenticação. Se você não solicitou a recuperação, ignore a mensagem.

Para compatibilidade com outras aplicações APOIS que ainda utilizam link: redefinir senha pelo navegador. O link é opcional; o código acima não exige abrir links.
