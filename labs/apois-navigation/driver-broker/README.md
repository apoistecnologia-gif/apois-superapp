# Driver broker candidate (lab only)
Separate Edge authentication boundary and HMAC private broker. The login JWT is used only by getUser. A signed short-lived envelope carries the verified actor; the broker reloads fresh authoritative proof and issues a scoped one-use route token. Dedicated persistent admission store must be separate from existing shared scoped issuance/admission store. No live endpoint, key, DB, network listener or deployment configured. Test uses in-process Request/Response, not live HTTPS. TLS termination, secure key provisioning/rotation, real DB binding, session revocation, latency, deployment hardening and physical-device validation remain gates. Do not enable on production. Reference: https://supabase.com/docs/reference/javascript/auth-getuser

## Modo local exclusivo
Configuração experimental explícita localOnly=true no proxy e broker: somente target, sem coordenada de origem, sem chave Ed25519 de roteamento ou store de emissão. O broker rejeita configuração mista e permit mesmo se assinado; a autenticação, HMAC, admissão antirreplay e prova fresca do banco continuam obrigatórias. O modo remoto original permanece separado. A variável candidata APOIS_NAVIGATION_DRIVER_LOCAL_ONLY não foi configurada em nenhum ambiente. Não é deploy, nem aprovação de produção.
