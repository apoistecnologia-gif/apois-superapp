# Dynamic routing field lab
V2 physical evidence: map rendered and GPS 2.5 m, ~8299 m from fixed-route origin; offline voice available but audible speech and moving navigation remain untested. This stage tests six routes via the actual Valhalla graph and an isolated authenticated loopback gateway, changing origins with fixed destination, validating snapped endpoints, geometry and voice/banner content. Coordinates are public reference samples, not the user's real location. No route graph or service is deployed, no production permission changes, no network-enabled APK. An actual device dynamic route requires a reachable service or an on-device routing engine; the lab bearer is not production ride authorization. Source is freshly downloaded Piauí data; hashes retained. The full Northeast graph has separate prior evidence.
