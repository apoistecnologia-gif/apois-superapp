# Grafo piloto compatível com Valhalla Mobile — laboratório
A evidência do servidor anterior (run 45741522837) informa versão 3.9.1-e73132a7d; o wrapper Android 0.6.3 fixa Valhalla 3.6.3 (e2f017b16080f49203de245a211b09efab09cf72). Não reutilizar o grafo 3.9.1 como se fosse compatível. O CI usa a imagem oficial 3.6.3-amd64 resolvida no run 45742736704, fixada por digest, e verifica a versão real do serviço local; falha se indisponível ou divergente. O grafo retangular Picos/Itainópolis é gerado de OSM e submetido aos testes dinâmicos já existentes. O tar é validado sem extrair arquivos, incluindo offsets/IDs/tamanhos do index.bin, SHA256 e limite de 128 MiB. A versão do grafo permanece inativa e só é disponibilizada como artefato temporário de CI se todos os testes passarem.
Não é grafo de todo o Nordeste nem prova de compatibilidade JNI: a próxima etapa deve rodar o mesmo tar no Android e medir tempos e memória, confirmar instruções e rejeição de pontos fora do grafo. Nenhum serviço publicado; nenhuma alteração em produção.
