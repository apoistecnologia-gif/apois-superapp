# Passenger local MapLibre proof (lab only)
Verified Android asset pack from cartography run 45539272618, using the trusted pack ID. Web proof serves a disposable same-origin copy, hashes every asset before loading, uses memory-backed PMTiles ranges and a unique MapLibre custom protocol for tiles/glyphs. No public tiles, paid APIs, user coordinates or remote map fallback. Browser runtime uses MapLibre GL JS 4.7.1 and PMTiles 3.2.0; dependencies are installed only in runner temp. The CI artifact is temporary, not production distribution infrastructure. Later production candidate must build its own verified asset pack, resolve license and update policy, and supply this adapter and an approved active catalog to private Passageiro pilot-config.ts. Browser rendering is not Android WebView or physical GPS. References: https://maplibre.org/maplibre-gl-js/docs/API/functions/addProtocol/ and https://docs.protomaps.com/pmtiles/maplibre .
