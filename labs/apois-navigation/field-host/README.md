# Infraestrutura de homologação física — NÃO publicada
Configuração candidata para Linux com Docker Compose, domínio de teste próprio e TLS válido. Não é configuração de produção, não cria servidores, DNS ou contas, nem usa Supabase. A V2 continua sem internet. Valhalla: loopback:8002; gateway: loopback:8003; Caddy: HTTPS 443 (HTTP 80 para ACME). Só POST /route chega ao gateway; /healthz fica local. Sem access log de coordenadas. Credencial de 64 hex gerada localmente, arquivo privado 0600, validade absoluta de até 15 minutos; não colocar no GitHub, APK ou chat. Não há renovação automática. Encerrar os containers após o teste. O gateway rejeita fora do retângulo Piauí, não autoriza corridas reais. O piloto utiliza mapa de 3,9 MB, não o grafo Nordeste integral. A imagem de Valhalla está fixada por digest; Node/Caddy exigem referências por digest para implantação; o CI resolve candidatos para validar a sintaxe, sem escolher automaticamente versões de produção. O preflight local rejeita tags mutáveis. Docker logging driver none desativa retenção de stdout/stderr dos três serviços; isto não comprova ausência de arquivos de log internos do Valhalla ou de logs em proxies externos. A inspeção no host real ainda é obrigatória. A configuração não foi executada em servidor nem inspecionada em rede pública.
Pré-requisitos: Linux disponível, DNS dedicado, portas 80/443 livres, firewall, dados OSM do piloto e armazenamento; verificar cgroup/RAM. Não iniciar sem autorização expressa do proprietário da infraestrutura. Teste de configuração CI usa somente placeholders e não sobe serviços. Se não houver host disponível, a alternativa é desenvolver roteamento embarcado (trabalho adicional, não implementado). Não usar instâncias públicas de demonstração.

Use `bash preflight.sh` para checagens locais somente leitura após provisionamento autorizado. Não inicia containers. O gateway exige arquivo regular privado, proprietário igual ao UID do processo, tamanho limitado e sem links simbólicos. O Caddy limita corpo e tempo de leitura. A validação CI não sobe endpoint público.
