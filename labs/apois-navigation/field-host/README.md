# Infraestrutura de homologação física — NÃO publicada
Configuração candidata para Linux com Docker Compose, domínio de teste próprio e TLS válido. Não é configuração de produção, não cria servidores, DNS ou contas, nem usa Supabase. A V2 continua sem internet. Valhalla: loopback:8002; gateway: loopback:8003; Caddy: HTTPS 443 (HTTP 80 para ACME). Só POST /route chega ao gateway; /healthz fica local. Sem access log de coordenadas. Credencial de 64 hex gerada localmente, arquivo privado 0600, validade absoluta de até 15 minutos; não colocar no GitHub, APK ou chat. Não há renovação automática. Encerrar os containers após o teste. O gateway rejeita fora do retângulo Piauí, não autoriza corridas reais. O piloto utiliza mapa de 3,9 MB, não o grafo Nordeste integral. A imagem de Valhalla está fixada por digest; tags de Node/Caddy são candidatas e precisam ser fixadas por digest antes de implantação. A configuração não foi executada em servidor nem inspecionada em rede pública.
Pré-requisitos: Linux disponível, DNS dedicado, portas 80/443 livres, firewall, dados OSM do piloto e armazenamento; verificar cgroup/RAM. Não iniciar sem autorização expressa do proprietário da infraestrutura. Teste de configuração CI usa somente placeholders e não sobe serviços. Se não houver host disponível, a alternativa é desenvolver roteamento embarcado (trabalho adicional, não implementado). Não usar instâncias públicas de demonstração.
