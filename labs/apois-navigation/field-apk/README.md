# APK GPS físico Piauí — experimental, isolado
New package br.com.apois.navigation.field.lab; does not replace earlier APK or official apps. Actual GPS only, foreground; stop/reselect on pause, no Internet or background location permission, no login, rides, payments, location storage, backend or external launch. Offline PMTiles and fixed routes from verified workflow 45733321788. Entry within 35 m of the snapped route origin, accuracy <=20 m and recent accepted fix; GPS deviation suppresses guidance and no rerouting. Voice uses only locally available pt-BR TTS. No route selection by address, no dynamic routing. Physical verification pending. Test as passenger or stationary, obey signs. Never use the phone while driving. Do not extrapolate from this pilot to whole Nordeste.
