# Capacitor bridge, stage 5
ApoisNavigationLabPlugin is installed only in generated app br.com.apois.navigation.compat.lab. The non-exported library Activity uses the real ApoisNavigationScreen with an empty NavigationUiState and a local background style (no street data, no network). It is a native transport prototype, not yet live navigation. open requires a rideIntent listener and a synthetic lab-* ID, returns random sessionId; update requires matching session and increasing snapshot revision; close checks session. Native user action emits rideIntent with ride ID/revision, action/rating; no database writes. A host must send a newer authoritative snapshot after each action. No real PIN, real location, TTS ownership, map tiles or production bridge yet. Process death closes the ephemeral session; no persistence. Actual WebView event delivery, activity rendering and Android back/configuration behavior remain device-test gates. No APK or production source changed.
