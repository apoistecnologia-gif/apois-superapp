## Disposable service integration
The host compatibility workflow now checks out the exact public migrated Motorista source commit without persistent credentials, runs the existing QA290 driver installer inside a temporary scaffold, and compiles a passive instrumented copy in the Capacitor lab. It does not register that service in the manifest or execute its network code. The QA235 insertion point is tested separately with an anchor-shaped copy; full generated QA235/236/239 host is not yet compiled. Source START/STOP/destroy invalidates the old source epoch; subscribers never migrate to another epoch and cached fixes predating source start are rejected. Before real account integration the host must explicitly invalidate navigation on logout/account switch (including a token-only account transition), and rearm only a verified current ride. No production edits.

A queued callback now carries both the source epoch and the consumer ticket captured before dispatch; switching legs within the same service invalidates the old ticket. The capture time must be at or after both source and consumer start. No active source returns LOST without starting any GPS service. Lost/poor quality clears stale location, ETA, and maneuver state while preserving route geometry for context.

## Live presentation and voice contract
The live surface uses the existing ApoisNavigationScreen (MapLibre), exposes a compact GPS status in the existing ride panel, and disposes its model on route or leg change. A voice permit must be provided by the future authenticated host after it stops the previous navigation voice. No permit means silent navigation. Foreground, quality, mute, completion and subscription revocation gate speech; source/consumer revocation always invokes cleanup even if the ride predicate has become false. The production permit issuer and real Activity remain unregistered and unimplemented. No new permissions or production changes.

## Native reroute budget
NativeRerouteGate ports the existing JS rate policy to Kotlin, with monotonic source capture time and opaque request tickets. Limits: 2 reliable deviations, accuracy <=25m, deviation >50m, 15s cooldown, 3/minute, 20/leg, one in flight. The live model currently evaluates in offline mode because no route server/resolver is authorized or installed; it spends no requests and clears stale maneuver/ETA on SDK-detected deviations. OffStepOnRoute is shown as checking rather than a claimed full deviation. Route provider and replacement within a single leg (preserving budget) remain next. Voice permit release is idempotent.

## Authorized route resolver
The native model may now accept an explicitly injected resolver and independent regional destination. Default remains null/offline; no deployed endpoint, public demo, credentials or production wiring. The HTTPS Valhalla client uses POST /route, pt-BR OSRM instructions, bounded response size/time, no redirect or retry, and checks geometry and endpoints against the regional bbox. Accepted replacements update the navigator inside the same model/leg budget; loss, cancellation, restored route or invalid session suppress application of late responses. Physical networking and server-side authentication/rate limits remain pending. The budget currently lives in the active model instance (not durable across Activity/process recreation). The 150m endpoint tolerance is provisional.

Reroute response application now additionally requires the still-pending opaque ticket, a current foreground session, a fresh <=25m fix and continued deviation. Background transition cancels the in-flight job. A cancelled job enters its finally block even if cancelled before contacting the resolver; failed/expired authorizations still consume the budget. Cancellation interrupts IO where supported; socket connect/read deadlines bound ordinary failures but physical interruption of DNS/TLS/transport has not been measured.

## Leg-scoped resources and bounded in-memory route cache
The future authenticated host must own one LegRouteResources<Route> for a verified ride and phase, retaining it across Activity recreation and external fallback/re-entry. A new model attachment does not reset rate counters. Detachment cancels the model's job but leaves the ticket pending until that job settles; concurrent attachments and stale attachments are rejected. Closing the host owner invalidates tickets and clears cache. The exact-origin, fixed-destination cache retains at most four validated routes for 30 seconds in RAM only, no rounding, no disk or cross-owner sharing; only a freshly validated network response is cached and a hit never extends TTL. Cache hits conservatively count against the request authorization budget, and require online/foreground and current GPS checks. There is no process-death persistence or operational host owner yet; backend enforcement is still required. No production wiring.

## Session controller ownership
NavigationSessionController now exposes a lab-only routingFor(currentToken,target,resolver) factory. It refuses stale tokens and changed targets; preserves the same owner and request counters during fallback; closes resources on verified phase transitions or controller close. Cached coordinates are discarded on detach/fallback (expired cache entries are otherwise evicted on access, not by a timer). The model rejects an initial route whose end is outside the owner's provisional 150m tolerance. The real authenticated host must reuse this controller across Activity recreation and close it on logout/account switch; this is not yet wired. No persistent budget after process death.
