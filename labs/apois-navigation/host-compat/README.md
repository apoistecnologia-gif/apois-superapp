# Compatibilidade com o host Capacitor 8.5.0
Gera um projeto descartável usando o template oficial Capacitor, verifica AGP 8.13.0/Gradle 8.14.3, compile/target 36 e minSdk 24, e então adiciona somente ao host de teste o módulo da interface Ferrostar. O host de teste sobe minSdk para 25, requisito do SDK. Não altera a política de suporte do aplicativo real. Não usar tools:overrideLibrary para contornar minSdk. Se integração exigir AGP/Kotlin superior, avaliar alternativa compatível ou migração separada; não atualizar o app por este laboratório.
O teste inclui AAR metadata, merge de manifesto, compilação Java/Kotlin e unit tests. Nenhuma tarefa assemble, bundle, install ou publicação. Não testa D8/R8 completo, execução no dispositivo, todos os plugins nativos do APOIS, Firebase ou assinatura. Não inicia navegação real nem acessa backend.
