# Follow-up safeguards
Native close emits SESSION_CLOSED after local state and callback are cleared. Host ignores events from any other session and cancels pending pickup timer. Replay resets old navigation UI at each leg and stops with an explicit error if input is exhausted without SDK arrival; no simulated completion is promoted to business state. The host retry is limited to one attempt for observed dependency transport errors and uses the same Maven repositories and pinned versions. No production registration or APK.
Driver integration audit: scripts/install-motorista-qa290-driver-location.mjs restores the current DriverLocationService and its foreground location pipeline, existing ACK, stationary GPS updates, and native auto-arrival. Future live navigator must consume this pipeline rather than register a second GPS service; the build-time source is in the protected submodule and needs inspection before any live adapter. Do not change the operational upload interval merely for navigation. No live GPS implementation in this commit.
