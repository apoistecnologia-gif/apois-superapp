# Voz pt-BR — experimental
The observed mixed prefix "In 300 metros" is normalized to "Em 300 metros", without translating street names or altering directions. Configure the native Android TTS engine for pt-BR, fail silent if the country locale is unavailable, prevent duplicate utterance IDs, and release audio/close on cancellation or session end. The adapter is not wired into the production app or even the lab screen yet. Unit tests exercise only text, readiness, mute, dedup and closed session. Compilation checks SDK types; audio focus, installed voice data, audible speech, background lifecycle and exclusive ownership with the existing DriverVoicePlugin still require device validation. No forced external engine download or paid voice API.
