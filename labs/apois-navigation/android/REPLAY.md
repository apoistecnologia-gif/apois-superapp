# Native replay prototype
The bundled JSON is the initial synthetic 1.336 km route from successful run 45534656564 artifact 14986856285. It is actual Valhalla output with pt-BR voice/banner instructions, not a road route in Brazil. The vector style renders the same fictitious grid locally. The Android model uses the SDK's native UniFFI navigator, simulation and PortugueseVoiceObserver, never a live GPS provider. Session token changes cancel old replay; background pauses updates and clears voice. UI state and spoken instructions are forwarded to the existing native screen. No live reroute, operational RPC, commercial map, production build or APK. Compile checks are not runtime proof; physical validation and lifecycle/audio tests remain mandatory.
