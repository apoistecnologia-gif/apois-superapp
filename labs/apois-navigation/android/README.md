# Native full-screen navigation surface (stage 4)
APOIS red/white Material3 Compose UI, real Ferrostar PortraitNavigationView and MapLibre, custom progress panel, destination and ETA, pickup PIN request, finish slider, compact rating. All ride mutations are intents for a future authorized host. No live RPCs, external map calls, production app edits or APK. Source only until compile/test pass; then emulator and physical visual validation are still mandatory. Host must revalidate action identity/revision, GPS, server authority and confirmation. A terminal navigation state is not a terminal ride state. Future host must stop native navigation at terminal ride state and retain map/provider legal attribution; verify map overlay and accessibility on real devices. No production style URL or API key included. The laboratory uses Gradle 9.2.1; host compatibility remains unproved.
