# Painel experimental de seleção independente
Módulos ESM isolados, sem importação em src/routes, sem endpoint ou chamada request-ride. O host de homologação injeta catálogo OSM versionado (somente linhas explicitamente ativas), transporte de confirmação privado, instância MapLibre dedicada com evento click lngLat e callback de retorno. Não reutilize o mapa Google existente nem coordenadas derivadas dele. O painel não monta sem enabled:true e não cria corrida. O retorno descarta seleção, cancela transporte e remove listener do mapa; o host retorna ao fluxo atual sem transferir pontos. A seleção confirmada é consultável somente enquanto válida; a integração ao request-ride requer validação do schema e do despacho. O catálogo regional continua desativado. Os testes usam mapa/DOM sintéticos, não demonstram renderização real de PMTiles ou homologação física. Para executar no checkout: node --test experimental/apois-navigation/ui/passenger-panel.test.mjs (Node 24).
