# Revisão de corrida experimental v21
Controlador independente, desligado por padrão; não importa o SDK Google ou Supabase e não monta nas telas atuais. O host deve usar confirmedInput() do painel OSM, fornecer transporte para servidor privado autorizado, mostrar o valor retornado pelo quote, e invocar submit(true) somente após toque explícito do usuário. Rejeita expiração, exige nova confirmação em price_changed e bloqueia cancelamento/retorno ao fluxo ordinário quando o resultado da criação é incerto. A tentativa usa sempre a mesma chave, inclusive após expiração, para recuperar corrida já vinculada. Não persiste estado após encerramento do processo: antes de ligar em aparelho, implementar journal de recuperação e consulta de corrida ativa, nunca criar automaticamente com nova chave. Nenhuma chamada real configurada.
