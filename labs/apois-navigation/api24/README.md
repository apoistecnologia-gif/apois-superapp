# Variante external-only API 24 — primeira prova de compilação
Escopo: fixture descartável, não produto distribuível. Usa Capacitor 8.5.0, AGP 8.13.0, Gradle 8.14.3, minSdk 24/compile e target 36, fonte Motorista fixada em 9fc171050d8b5703540c49d19a8f1e9f5162775f. Não adiciona probe, Ferrostar, MapLibre, PMTiles, bridge interna ou nova implementação de GPS/voz. Usa os Java originais do Motorista (GPS e voz, com o atraso histórico QA290 de 2200 ms), plugin externo e bolha existentes no superapp, em namespace descartável. A compilação e a inspeção do manifesto mesclado e da árvore de dependências são gates; nenhuma assinatura, assemble, bundle, APK ou instalação.
Limitação: este fixture não gera o host final QA290 completo, não copia seus overlays de GPS/voz/retorno, não registra serviço no manifesto e não verifica os plugins restantes, nem execução em dispositivo. O teste JS do seletor desligado confirma que o callback original é chamado sem consultar a bridge. Não afirma compatibilidade operacional do produto.
Achado preexistente: scripts/android/APOISReturnBubble.java usa TYPE_APPLICATION_OVERLAY, API 26, sem seleção alternativa para API 24/25; o catch mantém o fallback pela notificação QA236. O instalador QA239 reporta supported desde API M. Teste físico e eventual correção do legado exigem escopo separado; não modificar o original neste laboratório. Google Maps/Waze não são substituídos, tampouco há prova física nesta etapa.
Próximo gate: validar a geração do host QA290 completo sem instrumentações do SDK interno, preservar assinatura/manifesto/voz e fluxos externos e testar API 24/25 reais. Não modificar minSdk em produção. A seleção e distribuição da variante final dependem de autorização.
